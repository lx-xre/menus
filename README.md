 📝 Menús - Sistema de Navegación en Laravel 7

Este proyecto es una aplicación web desarrollada con Laravel 7 que implementa un sistema de navegación entre vistas utilizando Blade y herencia de plantillas. Cada sección tiene su propia vista y los botones del menu cambian de color para enfatizar la seleccion.

## 🚀 Características

- Menú horizontal con tres secciones: Inicio, Fotos, Contacto
- Cada sección tiene una vista propia y contenido distinto
- La opción activa del menú se resalta según la vista mostrada
- Layout compartido con pie de página fijo en todas las vistas ^^

## 🔧 Tecnologías utilizadas

- Laravel 7
- Blade (sistema de plantillas)
- Bootstrap 4 (vía CDN)
- PHP 7.x
- XAMPP / Composer
